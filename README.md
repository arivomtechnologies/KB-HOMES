### Features & Architecture
- **Theme:** Apex luxury dark charcoal (`#0B0B0B`, `#111111`, `#181818`) with brushed gold accents (`#C9A84C`).
- **Framework:** Angular 21 with Standalone Components & Signals.
- **Styling:** Tailwind CSS v4 with custom design tokens.
- **Animations:** GSAP & ScrollTrigger (Left/Right interactive project slider, count-up numerical stats, custom gold magnetic cursor, top scroll-depth indicator).
- **Interactive Tools:** Real-time Construction Cost Estimator with material breakdown.
- **Direct Engagement:** Floating WhatsApp integration connected to `+91 73974 13423`.
